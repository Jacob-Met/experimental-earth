    05 / CHALLENGE AN ASSUMPTION

    Which infiltration rates survive the readings?

    Compare explicit alternatives using the current storm and geometry. Use calibration readings to order the candidates; keep other readings aside to challenge their predictions. Rates are hypothetical capacities, not measured soil properties.

    Enter 2–9 distinct rates separated by commas. Each rate applies to every cell of that surface in the chosen scenario. Nothing is automatically applied to the site.

    Does the calculation interval change the conclusion?

    After comparing rates, repeat their reading predictions at finer supported intervals. This can expose numerical sensitivity before a modeled fit is treated as evidence about the place.

    Readings must describe this same place, scenario and weather event. Assign their roles in the notebook below; legacy or unassigned readings remain excluded. A ± band is your stated tolerance, not a probability or confidence interval. Off-step predictions interpolate between solver snapshots; changing assumptions or roles clears the comparison. Reusing held-aside readings to tune candidates no longer provides an independent challenge.

    06 / CLOSE THE LOOP

    Test it against a reading

    Record a manually obtained ponding-depth observation and its source. This changes the evidence record, not the model parameters. A discrepancy is useful evidence, not a failed measurement.

    Compare assumed infiltration ranges to find a consequential missing material measurement.

    Bring in a measurement table

    CSV columns: cell,minute,depth,uncertainty,unit,source. For timestamped logger readings, replace minute with timestamp,event_start; both require ISO dates, seconds and explicit UTC offsets (for example 2026-10-25T12:30:00Z). The declared event start converts original timestamps to minutes; it does not verify sensor synchronization. Original clock tokens are retained. Units must be mm, cm or in; both depth and ± uncertainty use that row's unit. Optional scenario and use columns assign evidence explicitly. Every reading must describe this site's event.

    Map original logger station IDs

    For tables with a station column instead of cell, declare each station's placement and its source. Names do not establish physical location. Clear this map for ordinary cell tables. Changing it retires the preview.

      Import keeps the supplied filename, row and original quantities. That records provenance supplied by you; it does not independently verify a physical measurement. The notebook holds up to 100 readings.

      Scientific boundary. This numerical sandbox uses a finite-volume surface-water transfer approximation, constant infiltration capacities and a simplified open-edge outlet. It omits infiltration decline, subsurface storage, drainage infrastructure, site-specific slopes, rainfall variability and calibrated roughness. Passing conservation checks means internal arithmetic is coherent, not that physical runoff or intervention effectiveness has been validated. No data leaves your browser.
