# Screen the observed source before opposite-geometry simulation

The optional profile-model comparator now evaluates each declared rate on the original study target first. Calibration and held-aside challenge checks apply only to that original target. Only retained rates spend simulation work on the opposite geometry. Every accepted candidate still contains both geometry results under the same selected model and receiving layer; all hypothetical layouts continue to use frozen original support.

Both existing and proposal geometry are checked for unsupported crests before screening starts. An excluded rate cannot hide an unsupported geometric declaration. The existing-source cache remains keyed by source geometry, dimensions, weather, surface, layer and rate; proposals remain local to each comparison. The all-declared and explicitly fixed-rate paths continue to evaluate both geometries.

This changes the work/refusal contract intentionally: opposite-geometry numerical/event refusals for a rate rejected by original evidence are no longer attempted. It does not certify those unexecuted runs. Accepted model values, rate parameters, physical process versions and the3M limit are unchanged. No threshold relaxation or partial-population result is introduced.
