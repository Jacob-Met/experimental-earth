## Process contract

Rain is uniform during the declared storm and stops at its actual cutoff. Each graph interval freezes head ordering and proportional outflow requests. Strictly downhill edges form a directed acyclic graph. A node receives the full piecewise timing of upstream outflow; constant-node wet/empty transitions allocate dry-cell uptake before outgoing flow. Profiles are propagated downstream instead of replacing them with a whole-interval average.

This is a different allocation/process hypothesis from the maintained split model. Exact constant-node events do not make graph dynamics exact. There is no convergence or validated field-optimality claim. In particular, each interval freezes graph direction; this is not an independently validated moving wetting-front model. Duration exposure uses outer-step snapshot interpolation, and aggregate ponding peaks use snapshots; neither is an exact continuous-time exposure guarantee.

Finite receiving layers/hypothesis families and declared crests are refused. Closed internal walls are supported. Dense finite graph inputs, unique valid edges/outlets, finite inventory/requests, at most576cells/1152edges/96boundary nodes and a safe integer budget are checked before graph access. Positive event durations that cannot be represented refuse. Each node admits at most4096 incoming profiles; cumulative event work is bounded by3,000,000 across original evidence and all layouts. A finer comparison shares the remaining budget with the private original charge. Failure produces no partial complete comparison. Floating-point mass checks use a relative1e-8 tolerance, not bitwise conservation.
