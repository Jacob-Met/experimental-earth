# Explain conflicting original-time temperature targets

Open `sky-target-conflicts.html` from the common target-margin page. It accepts
the complete saved three-profile record, a saved target-margin inquiry, or its
own saved conflict inputs. A three-profile record opens as an unapplied draft;
explicitly choose the desired original times, temperature components, ceilings
and attribution before calculation. The two declared change times and all
original observation bands remain together.

The complete common-margin comparison answers whether one shared set of three
profiles can satisfy every ceiling. The conflict explanation adds a necessary
group of ceilings when the full target set is incompatible. The authored example
retains all24 original observations and32 individually attainable targets. Its
identified group contains the lower-store ceiling at07:30UTC and the surface
ceiling at12:00UTC. A separate shared-profile witness demonstrates feasibility
when either member is omitted from that group.

## Reading a removal proof

Choose a member of the displayed group. The same fixed profiles must satisfy
every original observation and all the other group members. The omitted member
is strictly violated. This proves that it is necessary within this particular
group. The complete table still shows every authored target, including targets
outside the group; those other ceilings are not requirements of the removal
proof. Choosing a proof view does not edit any target or saved input.

Inspect any original receiver and original time without recalculating or choosing
a new profile. Both temperature components keep the exact additive values and
the separate original numerical endpoints. Each removal witness also retains
the three normalized profiles, every original observation, and all numerical
observation-band statuses. The original common-margin comparison is available
in a separate disclosure below the conflict proof.

The identified group is **inclusion-minimal**: removing any of its members makes
that group feasible under the unchanged observations. It is not claimed to have
the fewest members among all possible conflicts. Numerical replay, additive
compatibility and physical validation remain separate. No intermediate time,
unselected target, measured sky history or intervention is inferred.

## Exact proof and reuse

The original nine nonnegative coordinates represent three four-bin profiles;
each bin-zero mass is the complement of its other three masses. All original
observation rows and the three simplex rows remain mandatory. For a target row
`f_i(x) = z_i + a_i*x`, the hard ceiling is `a_i*x <= ceiling_i - z_i`.
Every64-combination additive identity is checked before projection.

The maintained exact linear solver supplies feasibility and Farkas certificates.
For `A*x <= b` and `x >= 0`, nonnegative multipliers with `y*A >= 0` and
`y*b < 0` prove incompatibility. Zero target multipliers may be removed from that
verified certificate while every original observation row remains. Deterministic
source-order deletion then tests each supported target. A target is removed only
after a verified contradiction for the smaller group. Every retained member has
a feasible removal point, rechecked against the final group minus that member.
Its three normalized profiles and all64 product masses are reconstructed and
checked against every original constraint and every required target.

The new consumer reuses the fresh common-margin computation and its original
thermal basis. If the best common profile is feasible, its already replayed
profile provides the full target feasibility seed. Otherwise, the margin dual
is tested as a Farkas certificate on the exact hard-target matrix. The test must
find an exact strictly negative contradiction; complementarity is not assumed.
If an entire target row exceeds its ceiling even at its minimum basis value,
the three simplex multipliers and that target provide a singleton certificate.
Both seed paths are verified against the current complete source-derived matrix.

This reuse matters operationally. The first retained actual-coefficient probe,
which solved the full target family again before deletion, exhausted the
cumulative arithmetic allowance. The verified margin seed lets the same original
example finish its conflict search within the unchanged allowance. The failed
probe remains evidence; it is not counted as a passing course.

## Complete-query limits

The source contract retains3–24 original observation records, at most3 complete
original receiver declarations, four bins, exactly two declared internal changes,
at most24 original intervals and1–50 distinct original time/component targets.
The conflict series permits at most52 feasibility solves,2048 total pivots and
4,000,000 counted solver arithmetic operations across all its solves. It reuses
the maintained target solver's admission of at most101 rows and4096-bit exact
fractions; no solver algorithm or prior six-/nine-coordinate limit is replaced.

Before geometry or thermal evaluation, the outer query reserves the complete
parent inquiry and as many removal replays as there are authored targets. Whole
query maxima are2580 thermal courses,61,920 course intervals,151 witness profiles,
12,288 linear pivots,24,000,000 counted solver operations and64MiB of complete
report output. A compatible result reuses its parent numerical witness. An
incompatible original record withholds target conflict and removal claims.
Exhausted allowances or an incomplete proof refuse the entire new result.

## Source custody and consumers

Saved conflict files contain exactly `kind`, `model`, `readings` and `query`.
Reports, certificates, group membership and replay values cannot be imported as
source. Download admission checks the final bytes and uses compact JSON when
pretty formatting would exceed the5MiB source allowance. A fresh open recomputes
the complete result in a new worker.

The target-margin and conflict pages share the maintained editor/controller.
Changes retire the current result; Apply, Cancel, held file reads, superseded
workers and detached controls retain their generation and source-identity guards.
The old target-margin API and complete public report remain unchanged. The new
execution seam exposes fresh internal context only to source-owning callers;
worker messages and saved inputs never carry that context.

Focused controls cover a necessary pair with a redundant target, singleton
conflicts, compatible and original-incompatible families,50-target admission,
nonadditive and forged proofs, exact cumulative work exhaustion, a zero-auxiliary
margin seed, complete original-time replay and large-source export. Independent
Fraction checks reconstruct unfamiliar feasible vertices and Farkas/removal
certificates. Actual browser qualification covers both maintained consumers,
fresh source-only reopening, all original receiver/time bindings, stale controls,
keyboard access and narrow layouts.
