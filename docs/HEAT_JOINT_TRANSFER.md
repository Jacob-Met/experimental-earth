# One shared explanation across original exposures

Separate one-exposure comparisons can each succeed by retaining different original candidates. The joint transfer consumer asks whether one frozen original alternative satisfies every retained exposure. It does not fit a new family or silently choose a favorable subset.

In the existing transfer panel, include the current comparison or select two to eight downloaded original transfer files. The files must retain the same complete original investigation, including its candidate family and original calibration/challenge readings. Every exposure keeps its complete project, raw temperature CSV, association and initial-state declarations. Generated reference labels are editable; labels do not establish independent acquisition. Repeated observations do not become statistically independent through a new label.

The result preserves every original alternative and every separate comparison. If no common alternative remains, it lists every inclusion-minimal conflicting source set: no offered original survivor satisfies that set, but removing any one exposure restores some support. A singleton indicates an exposure that already contradicts the original survivors. A larger set can reveal a contradiction hidden by separate successful comparisons. Neither identifies which record is wrong, proves material change, nor excludes unoffered models.

An original investigation without calibration remains unknown. An already rejected original family cannot be revived by the new collection. Wide bands can preserve all original alternatives. Sources are never removed or refitted automatically. Explicitly removing one source invalidates the old result and requires a new comparison.

## Custody and execution

The consumer admits the complete collection before any evaluation. It permits at most eight exposures and 16 MB of original JSON, reuses the maintained transfer evaluator, and enumerates at most 255 finite source subsets. The full comparison runs in an owned browser worker. Source edits terminate pending work; replacement file selection immediately retires the prior collection. Failed reads leave sources missing. Reopening or comparing uses current original inputs only.

Schema `experimental-earth-heat-column-joint-transfer/1` stores original transfer inputs and reference labels, with no derived outcomes. Raw reopening recomputes all comparisons. Unknown cached-result fields refuse. Original projects compare by retained values rather than JSON key order; every original field must agree. The current application workspace remains unchanged.

## Evidence and limits

An authored probe uses three different forcing/initial-state courses whose individual results retain B, C and B from a five-candidate original family. Joint support is empty; source sets {1,2} and {2,3} are minimal conflicts. A matching-source control retains B. A separate eight-source control uses independently integrated point and window-mean values and agrees with all 18 conflicts of a known-support set oracle. These are model/software controls, not acquired physical validation.

The finite alternatives, source associations, supplied initial states and physical model remain assumptions. Common support is conditional compatibility, not unique identification, a probability, or evidence of source independence. Complete finite-set enumeration establishes only the retained collection's finite-candidate conclusion.

A retained original-input control also supports {B,C}, {A,B} and {A,C} separately. Every pair of exposures shares one candidate, while the complete three-source collection has none. Its only minimal conflict contains all three sources; checking pairwise conflicts alone would miss it. The inputs are authored model controls and remain in the native fixture for direct replay.
