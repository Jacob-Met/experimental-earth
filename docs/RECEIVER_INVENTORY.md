# Original receiver-water inventory

A draining layer's absolute stored water is a different observable from surface ponding. This continuation compares original aggregate liters across every cell of the investigated receiving surface against the maintained layer's retained-inventory snapshots. The event reference must match the original rainfall event and the person must supply an explicit affected-footprint association and source. An exact retained model time is required; the implementation does not interpolate an unobserved time or derive storage from water depth.

The consumer starts actual quantity, time and uncertainty blank and adds held-aside evidence. Original JSON may retain explicit calibration, challenge or unassigned roles. Calibration can exclude only supported draining explanations; held-aside inventory leaves calibration fit/order unchanged. Unlimited infiltration and closed *remaining-space* models do not define absolute initial/retained receiver inventory, so their inventory checks remain unassessed. An absent prediction is never evidence against a model.

The authored control has two draining parameter combinations with identical surface histories: (capacity5, initial0, coefficient1/hour) and (capacity10, initial(20−15 exp(0.5 ln(20/15)))/0.5, coefficient0.5/hour). An independently supplied initial zero-liter inventory challenges the second. An interval wide enough to contain both predictions retains both. A closed model that survives the surface-water course remains explicitly unassessed by this quantity.

No additional solver runs are introduced beyond the complete receiving-family comparison. At most32 original inventory rows are admitted; snapshot lookup uses binary search over the retained bounded simulation steps. Numerical comparison uses a64epsilon relative guard separately from the original uncertainty, not a confidence interval or physical accuracy claim. Source-only transfers are limited to4MiB and recompute on reopen. Neither inputs nor fitted parameters replace the active site.
