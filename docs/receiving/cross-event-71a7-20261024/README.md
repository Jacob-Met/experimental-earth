## Qualified source and behavior

The cross-event panel transfers the finite infiltration alternatives from a
calibration project to a separately declared storm project. It requires matching
observed geometry, surfaces and non-weather modeling assumptions. Only the first
event's calibration readings determine candidate order. First-event holdout and
second-event readings can reject candidates; neither silently retunes the model.
Both input projects, references and choices survive portable export/reopening,
which recomputes results rather than trusting a saved verdict.
