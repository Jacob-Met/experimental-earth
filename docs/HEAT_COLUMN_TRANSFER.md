# Challenge hidden-store explanations on another exposure

The application can carry an original finite capacity/conductance family into a separately declared heat exposure. It preserves the original calibration and challenge outcomes, both complete project inputs, every offered alternative, and the new temperature CSV. New readings never fit or rank parameters.

## Ordinary workflow

1. Save a two-store surface-temperature investigation in the existing heat evidence panel. In **Do the same hidden-store explanations work again?**, freeze the current investigation, or open its exported original project.
2. Open the exported project for the separate exposure. It must retain a complete two-store declaration at the same original place and scale. Surface absorption, capacity and reservoir exchange must remain unchanged. The new exposure retains its own explicit surface and lower-store starting temperatures and forcing schedule.
3. Explain the unchanged-material association, then open the original temperature CSV for the separate exposure. The maintained temperature-table adapter accepts explicit C/F/K units and instantaneous or interval-mean readings. Every row must declare `challenge` use. No role is silently converted.
4. Challenge the frozen alternatives. Inspect every original candidate, its status under the original evidence, and the separate-exposure predictions and bands. A previously rejected alternative cannot regain support by fitting only the new exposure.
5. Download both original sources. Reopening recomputes the comparison from the two original projects, the original CSV and the source association. It does not restore cached predictions or replace the current workspace.

Selecting a replacement retires that selected source immediately and disables comparison while current reads are pending. A failed read leaves the source missing; it cannot silently reuse the preceding file. Reopen a retained original bundle or select a valid file to restore it. Concurrent reads of different inputs have separate version guards.

The panel uses explicit frozen inputs. Editing the workspace later does not silently retarget an existing transfer result; freeze a new original investigation when that is intended.

## Meanings and limits

An original investigation without calibration has unknown transfer support. A family already rejected by original calibration or challenge readings cannot become supported through the separate exposure. Contradictory new readings can reject every originally retained candidate; broad bands can preserve all of them. Every original alternative remains inspectable in either case.

The consumer reuses `compareHeatColumnEvidence`, including complete-course admission, the maintained instantaneous and interval-mean operators, and arithmetic guards. It does not implement another heat solver. The new comparison applies the original capacity/conductance declarations while retaining the second exposure's explicit initial states and surface physics. Those initial temperatures are supplied assumptions, not inferred states.

A compatible finite alternative does not establish unique or measured material properties. Source associations and challenge role labels do not establish independent acquisition or prove that the physical material was unchanged. This software comparison does not itself validate the physical model.

## Original-only files

Schema: `experimental-earth-heat-column-transfer/1`.

Inputs are `originalProject`, `challengeProject`, `readingFile` (`name`, `text`) and `associationSource`. Each original project must satisfy the existing portable-project contract. The original CSV is limited to128KB and uses the maintained temperature-table parser, including original lexical values, units, source and row provenance. One derived byte bound covers export and reopen: two admitted4MiB projects, worst-case JSON escaping of the bounded CSV, and bounded metadata. Unknown top-level cached-result fields refuse.

## Evidence

An authored heating investigation leaves five original lower-store alternatives compatible at its calibration time. A separately declared cooling/weak-heating exposure, with explicit new initial temperatures, tests those frozen alternatives with a15-minute instantaneous reading and a30–45-minute interval mean crossing the35-minute forcing transition. Only one original finite alternative remains compatible with the supplied narrow bands. An independent augmented matrix exponential agrees with ten predictions across the five alternatives within4.13e-13°C.

The maintained tests include broad-band ambiguity, contradictory transfer, missing calibration, originally rejected families, new calibration-role refusal, changed place/surface-physics refusal, source-preserving export/reopen, mixed-unit originals, and a previously rejected candidate that matches the new exposure but cannot regain support. These are authored numerical and software controls, not acquired temperature validation.
