# All admissible gaps in original mean histories

The original-mean consumer can compare the entire selected course without first choosing a phase boundary. This additive child uses original NOAA bytes/rows or a native unpartitioned mean source. It preserves the existing declared-phase comparison. No original row gains an acquired `pre`/`post` role and no boundary is silently adopted.

## Restricted model, complete comparison

The declared model permits at most one descriptive change **between complete original observation supports**. Changes inside a mean window are excluded. Uniform-time remains an explicit conditional comparison operator; original sensor weighting remains reported or unknown. Mean support is never replaced by a point instant.

Sort positive-duration supports by start. A cut is admissible exactly when the maximum earlier end is no later than the minimum later start. Every change outside all support interiors induces one such prefix/suffix partition. Overlapping or same-start windows cannot straddle a valid cut. Singleton gaps are included. Original row indices remain inspectable even if input order differs.

For every cut, retain both exact affine mean regions and their refusals or rank deficiency. Where both regions are bounded, reuse the maintained joint response projection and continuous signed onset inference. Evaluate the displayed response at the gap start solely as a fixed reference; this is not a selected change time. Keep every signed onset interval separately. No rank, posterior probability, best fit, automatic adoption or causal interpretation is introduced.

Independently infer an unchanged line from **all original rows**, including overlapping windows. It is not a residual choice after successful partitions are pruned. A consistent repeated mean operator can support unchanged lines with unbounded slope. Likewise, insufficient operators in a partition remain an unbounded alternative, not evidence that no change is possible. A model rejection is distinct from unbounded inference or unchanged support.

It has no boundary or role fields. `experimental-earth-noaa-unpartitioned-means/1` retains the original source bytes/hash/URL, selected lines/correction, channel direction, bands/association/operator and model basis. The bridge shares unchanged NOAA parsing and source selection with the declared-phase receiver. Both preserve unknown acquisition weights. Source-only bundles contain only schema, original project and original input; reopening recomputes without replacing the active workspace. Parent source edits retire child output and late reads.

At most 64 original pairs yield 63 structural cuts. Complete global-plus-period pair work is preflighted before inference, capped at 100,000. One shared maintained 200,000 constraint-check budget covers the unchanged region, every period, joint slice and onset clipping. Vertex-pair, hull and onset-root work is accumulated across all cuts, capped at 250,000, 8,000,000 and 32,768 respectively. A per-cut geometric helper never resets the aggregate allowance. Exhaustion refuses the whole comparison; no successful prefix or selected partial result is returned. At an exhausted root allowance the next bounded cut conservatively refuses even if it might require no roots.
