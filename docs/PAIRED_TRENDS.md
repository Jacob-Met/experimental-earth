## Conditional mechanism

The earliest original pre-intervention instant defines the baseline origin.
For each offered slope, subtract slope×elapsed days from every original
pre-period treated-minus-comparison interval. Intersect those shifted intervals.
This retains the entire permitted baseline interval rather than fitting or
selecting one value. Original pairs attaining the extreme endpoints are retained
as witnesses. If the intersection is empty, that slope receives no later contrast.

For each compatible or boundary slope, shift every later gap back to the same
origin and subtract its entire permitted baseline interval. The result displays
each original later time, residual interval and exact sign relation, alongside
time beyond the last earlier reading. Later values never rank, select or refit
slopes. A finite family does not cover all possible trends, and extrapolating one
is a conditional model assumption rather than a causal estimate or forecast.

In an authored control, original pre gaps10±0.1 and12±0.1 one day apart reject a
constant gap. The offered0/1/2/3unit/day family retains2; a gap14±0.1 another day
later then has a residual near−0.2..0.2. In a separate ambiguous control, gaps9..11
atdays0/1 retain slopes−2/0/+2. A later gap9.9..10.1 atday3 yields respectively
positive, zero-spanning and negative contrasts. Picking one supported slope
would conceal the uncertainty. These controls are authored, not measured studies.

## Exact arithmetic and its boundary

The consumer reuses the unchanged maintained Chronos/WORLDLAW rational module;
[its pinned provenance](../vendor/chronos/PROVENANCE.md) includes original commit,
Git blob, SHA-256 and same-owner reuse/licensing scope. No new rational or general
affine solver is introduced.

Parsed binary64 readings and slopes are converted exactly to rational numbers.
Validated four-digit UTC timestamps yield exact integer millisecond differences;
division by86400000 produces exact elapsed-day fractions. All classification and
witness comparisons occur on rationals. Expanded records contain outward binary64
enclosures and exact numerator/denominator disclosures. Overview numbers are
explicitly rounded for readability; rounded labels never determine status. This does not recover
pre-JSON decimal text, authenticate measurements, establish error independence,
or produce statistical confidence. Shared measurement errors are not inferred.
The unchanged helper refuses arithmetic beyond4096bits. The consumer preflights
the whole offered family against576candidate/pair checks (9×64), never truncating
observations or candidates. Production runs entirely in browser JavaScript.

Zero-slope results agree with the old constant-gap path where its floating-point
arithmetic is resolved. Exact arithmetic can resolve that path's numerical-contact
cases; it does not change the supplied bands. A point baseline is a boundary
case, not unique physical parameter identification.

## Original-source workflow

The default comparison uses the currently accepted original paired series.
Changes above retire the result; recompare the original series before proceeding.
A saved trend investigation contains only the original full project, paired
series, slope values and rationale. Reopening recomputes those inputs while
preserving the active workspace and parent investigation. Its source label says
**own reopened source**. Editing the parent does not rewrite that retained source;
**Use the current accepted paired series** explicitly switches back.

Original readings and declarations remain inspectable for each result. Input
edits retire conclusions, and a late file read cannot overwrite newer slope or
basis edits. Save and reopen share the maintained4MiB ceiling. Files may contain
private site and original source descriptions; nothing leaves the browser.
