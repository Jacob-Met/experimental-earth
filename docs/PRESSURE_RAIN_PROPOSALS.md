# Calibration-guided rainfall proposals with original gauge receiving

This additive comparison follows an accepted joint pressure-head investigation. It retains the complete original rainfall/duration/mechanism family and tests additional rainfall values separately. A user explicitly supplies rainfall proposal bounds, an original calibration notebook row, and the basis for those bounds. No active site or parameter is adopted.

For each original storm end and explicitly supplied pressure-head hypothesis, the bounded numerical helper tests the original weather intensity and both limits, then up to 44 sign-bracket center proposals. The selected original calibration depth guides proposals. Every tested point is retained and checked against **all** original depth calibration bands. The unchanged interval-rainfall overlap scorer then checks original calibration and challenge totals, and the original direct rainfall bounds also constrain eligibility. Held-aside water and rain never steer proposal coordinates or calibration eligibility.

The complete original comparison plus 47 possible runs per hypothesis per duration is reserved before any hydraulic run. The existing paired pressure ceiling of one million cell steps and aggregate three-million ceiling remain. Original gauge comparisons additionally have a complete 100,000-row cap. The original hydraulic and rainfall-overlap algorithms are unchanged.

The receiving example starts with an original 29 mm/hour offer that has no supported explanation. With declared proposal bounds 28–32 mm/hour, the retained explicit K10/A20/deficit0.4 model yields a 30 mm/hour point that passes the original depth and gauge evidence. The executed course retains 50 tested points, 25 calibration-compatible and one not contradicted, with 10,272 reserved cell steps. These counts are finite tested points, not independent evidence. A direct original gauge bound of 1–2 mm/hour rejects every proposed explanation.

A failed bracket does not prove that no admissible rain exists, and the proposals do not enclose a continuous feasible interval. Nearby deficit values 0.399999 and 0.400001 can both pass the authored tight depth bands after rainfall adjustment. A sole survivor among the original offered samples therefore does not identify a unique continuous physical soil property. The source is authored, not field validation.

The maintained child supports original-only download/reopen, displays its own imported project/event/target and original rows, and retires accepted results on edits, malformed replacement, stale file completion or parent replacement. Cumulative counter files are **not** interval-total files and are not accepted; the lost cumulative-counter successor must be independently recovered and qualified before adding that receiver. No counter differencing or invented baseline is used.
