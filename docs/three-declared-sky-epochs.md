A common four-bin sky profile applies in each of the three resulting epochs. The same profiles supply every receiver and both designs.

The original record supplies the constraints. Choosing two changes declares a model to investigate; the inquiry does not estimate a physical change time, recover a measured sky history, authenticate shared conditions, or validate an intervention.

## Maintained evaluator and exact coefficient model

The inquiry reuses `sampleProfileBasisGeometry` and `evaluateProfileOriginalBoundaryCourse`. For each unique receiver it executes all 64 combinations of one active bin in each epoch. Every combination retains the complete original course for existing/proposal and lower/upper geometry endpoints. All original clocks must agree, and every observed existing endpoint must be resolved across the whole combination family.

Ten reference combinations define an exact additive representation of the floating-point values produced by those complete courses. At each original time, target, geometry bound and thermal component:

`C(i,j,k) = C(i,0,0) + C(0,j,0) + C(0,0,k) - 2 C(0,0,0)`.

The formula is evaluated in exact rational arithmetic over the represented input values. Every one of the 64 original combination values is compared with that representation at every original boundary. An absolute discrepancy exceeding `1e-9 C` refuses the complete inquiry. This finite screen does not certify every possible mixed profile or establish a physical error bound.

Each normalized four-bin profile has three independent nonnegative coordinates; bin zero is its exact complement. Nine coordinates therefore describe the three profiles. Three simplex-sum inequalities and both sides of every original band give at most 51 original inequalities. The maintained exact linear algorithm has a separate nine-coordinate entry with these limits; its previous six-coordinate, 50-inequality API remains unchanged.

For every requested consequence, the solver returns a feasible primal point and nonnegative dual multipliers with equal exact objective values in the original matrix. An incompatible family returns an exact Farkas contradiction. The report retains the original projected rows, objective projections and certificates. Product masses from the three marginal profiles reproduce every additive observation and objective exactly. They express a mathematical coupling, not an observed sky history.

Displayed witnesses normalize approximate versions of the exact profiles and rerun the maintained original thermal evaluator. Their full original-time values, additive differences, numerical discrepancies and every original observation's band status remain distinct. A replay exceeding the same consistency screen refuses the complete inquiry.
