# Original readings against explicit longwave alternatives

This consumer connects the already retained surface-temperature evidence to an
accepted longwave investigation. It preserves original layer hypotheses, reading
values, uncertainty bands, sources and calibration/challenge roles. The observed
layer's explicitly declared emissivity and the original radiative schedule apply
to every candidate. The user must separately source the assumption that every
candidate's linear coefficient excludes longwave radiation. A declaration for
one saved layer is not silently extended to different candidate properties.

The source heat exposure and place must match exactly after canonical receiving.
The original linear-only prediction remains visible beside radiative predictions.
The existing temperature and absorbed-input evidence contracts own admission;
absorbed-energy readings in version 2 are retained and evaluated with the existing
exact absorbed-input evaluator. Adding outgoing radiation does not change the
absorbed incident input. Original model files and projects are never replaced.

## What the comparison establishes

The same finite alternatives are evaluated at two local temperature-error
settings, 1e-8 and 1e-10 degrees C. Each original observation time becomes an
integration boundary in a separate course for its calibration/challenge role; the consumer does not interpolate the minute display
samples. Results retain both predictions, both residuals, their absolute change,
and whether the supplied observation band contains both predictions, excludes
both, or receives different classifications. All readings remain available.

**Agreement at two settings is not a rigorous numerical enclosure**, a global
error bound, a physical confidence interval or evidence that the model describes
the place. The display intentionally says “inside at both settings,” not validated
or identified. Setting disagreements are not counted as inside both. Original
linear temperature and absorbed-input comparisons retain the prior arithmetic
guards. Calibration and held-aside challenge results remain separate. No ranking,
refit, inferred likelihood or adopted material is produced.

For a concrete authored mechanism control, A has absorptivity .4, capacity
40000 J/(m² K), linear exchange 10 W/(m² K); B doubles all three. Their original
linear temperature response is identical. With the same declared emissivity .9
and effective surroundings 5 °C, their radiative responses differ. This is a
conditional distinction supplied by the extra declared physics, not identification
of capacity independently of emissivity. Scaling emissivity with the other
coefficients restores the ambiguity.

## Work, numerical queries and refusal

The existing longwave mechanism admits up to 100 original query times and only
the two supported local settings. Its default call preserves the former response.
Calibration and challenge query grids are integrated separately, so changing a
held-aside timestamp cannot perturb the calibration numerical path or band result.
An energy-only inquiry still receives one full trajectory course.
Candidate pairs reuse the two-layer executor; an odd final candidate is duplicated
for execution and that cost is counted. An upfront lower bound sums every candidate
pair at both settings and for every actual role course. The runtime attempt budget is then shared across the entire
inquiry, including rejected steps. Exceeding 100000 attempts throws for the whole
inquiry; no completed-prefix survivors are returned. The unchanged linear model
also admits the full original exposure, including unobserved interval endpoints.

A separate exact exponential control at .37 minutes gives 84.073229147 °C.
Direct query integration gives 84.073229170 °C at the looser setting, while
interpolating the minute display would give 86.644824448 °C. This is why original
reading times drive execution. A fast-response boundary control produces an actual
3.53e-8 °C change between settings: a zero-width reading matching only the looser
result is retained as a setting disagreement.

## Product and persistence

The mounted panel accepts the current retained temperature evidence and the
accepted longwave source, then shows every original candidate in its original
order. A selected candidate exposes all temperature residuals, any absorbed-input
readings and source notes. Tables scroll within the panel at narrow widths and
support keyboard focus. No observation is removed because a candidate rejects it.

Source-only download canonicalizes declared fields and omits results. Reopening
recomputes independently without adopting the source into the current project.
Original-source mismatch, malformed values and work refusal clear old results.
A changed candidate declaration, radiation source or current project retires the
comparison; a delayed valid file cannot overwrite a newer edit.
