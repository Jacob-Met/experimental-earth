# Which original rainfall readings could be rechecked?

When original interval totals cannot all fit any nonnegative rainfall history, the existing gauge consumer offers an explicit recheck action. It evaluates every original calibration reading in turn with only that constraint excluded. All choices whose exclusion restores compatibility are shown with their original interval, value, uncertainty and source. Original evidence is never edited or relabeled.

A listed choice is not an accusation of measurement error and is not preferred over other choices. The inconsistency can instead concern source association, units, timing or uncertainty. No rainfall profile or soil rate is inferred. If no single exclusion works, multiple independent contradictions remain or more than one constraint needs reconsideration.

The exact existing history feasibility checker is reused. Complete base-plus-all-exclusions work is reserved before any answer is inspected; over-budget work returns no partial choices. The admitted64row limit bounds reservation below3million edge relaxations. Held-aside values never select recheck choices.
