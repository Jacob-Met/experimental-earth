# Exact empty intervals in the event research model

The event model remains `uniform-source-finite-event-midpoint/research1`; its physical and numerical process is unchanged. After normal graph, inventory, receiver and budget admission, and after the first charged flux evaluation, a constant-forcing call with exactly zero rain, every surface depth exactly zero and every receiver store exactly zero advances to the end of that call. This is an absorbing state of the admitted flux recurrence. No tolerance, depth clipping or positive-water shortcut is introduced. The outer model still visits later rain intervals and output snapshots.

This changes work accounting and therefore which otherwise valid long dry simulations fit the declared budget. It does not preserve prior work or refusal parity. For example, an arbitrarily long empty call can now complete where the former stiffness loop exhausted its step bound. Positive rainfall, nonzero stored water, malformed inputs and exhausted work still take their existing paths. Normal flux evaluation precedes the shortcut, preserving its nonfinite-rate refusals.

Qualification: eight source/rain/receiver combinations have exact numerical ledger, depth and peak parity against the kernel with only the shortcut removed. Five additional controls cover a huge empty interval, positive-rain step refusal, exhausted work, overflowing head differences and invalid rates. A complete nine-layout, two-rate, 12-hour mixed consumer has exact report parity excluding work/diagnostics, with charged work reduced from 71,160 to 37,080. This is a work-count result, not a universal runtime-speed claim or a new accuracy/convergence result.

Run `tests/mixed-placement.browser.mjs` with the documented Chromium sandbox environment; its added course opens raw declarations and receives all nine layouts through the dry tail. Existing event limitations and the maintained default remain as documented in EVENT_MIDPOINT_PROCESS.md.
